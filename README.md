💜 ARMY Universe

Um universo feito por fãs, para fãs do BTS!

O ARMY Universe é um projeto desenvolvido para reunir fãs do BTS em um só lugar, com notícias, curiosidades, músicas, jogos e conteúdos especiais sobre os sete integrantes.

🌌 Sobre o projeto

O objetivo é criar uma experiência interativa, moderna e futurista para a comunidade ARMY, celebrando a música, a trajetória e o legado do BTS.

✨ Funcionalidades

- 📰 Notícias: novidades e atualizações sobre o BTS.
- 👑 Integrantes: perfis de RM, Jin, SUGA, j-hope, Jimin, V e Jung Kook.
- 🎮 Quiz e jogos: desafios e curiosidades para testar seus conhecimentos.
- 💜 Comunidade ARMY: espaço para interação entre fãs.
- 🎵 Discografia: álbuns, músicas e lançamentos.
- 🖼️ Wallpapers: imagens para personalizar dispositivos.
- 📅 Calendário: aniversários e eventos importantes.
- 💬 Chat: espaço para conversas entre fãs.

🎨 Identidade visual

- Preto: elegância e modernidade.
- Roxo: identidade visual inspirada no universo ARMY.
- Efeitos futuristas, neon e animações.
- Design responsivo para celulares, tablets e computadores.

🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript
- Git e GitHub

🚀 Objetivo

Transformar o ARMY Universe em um espaço digital especial para fãs do BTS, reunindo informação, diversão e comunidade.
